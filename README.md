## Описание программы

**Progs** — это портативный менеджер установки программ для Windows, реализованный как один `.bat`-файл. Проект убирает рутину при настройке чистого ПК: вместо ручного поиска и запуска десятков установщиков вы заполняете простой текстовый список ссылок, а скрипт сам скачивает файлы, ставит их пачкой (выборочно, диапазонами или по заранее заготовленному пресету), чистит хвосты в реестре и ведёт подробные логи каждой операции.

Ключевая идея — **никаких зависимостей и установки**. Скрипт использует только стандартные средства Windows (`curl`, `powershell`, `choice`, `reg`), работает из любой папки, включая флешку, и корректно обрабатывает пути с пробелами и русскими буквами. Все рабочие папки (`links`, `Progs`, `Logs`, `profiles`) создаются автоматически при первом запуске.

## Быстрый старт

1. Скачайте репозиторий (**Code → Download ZIP**) или клонируйте его:
   ```
   git clone https://github.com/MrAdamod/Prog-.git
   ```
2. Запустите `Progs.bat` двойным щелчком.
3. Добавьте нужные ссылки в `links\links_download.txt` (формат `URL|имя_файла.exe`).
4. В главном меню выберите `1` — скачать, затем `2` — установить.

Подробное руководство — в [docs/USAGE.md](docs/USAGE.md).

## Функционал

- **Скачивание программ** — читает `links/links_download.txt` (формат `URL|имя_файла.exe`), качает через `curl` в папку `Progs`, пропускает уже скачанное.
- **Пакетная установка** — ставит `.exe` и `.msi` из `Progs`, поддерживает выбор диапазонами (`1-3 6 8-10`) или всё сразу (`A`).
- **Удаление из Progs** — выборочное или полное удаление установщиков с подтверждением.
- **Открытие ссылок** — `links/links.txt` (формат `URL|название`) открывает ссылки в браузере, тоже с диапазонами.
- **Работа с txt из меню** — открыть/дополнить `links.txt` и `links_download.txt` прямо из скрипта.
- **Очистка реестра** — удаляет разделы по списку `links/registry.txt` (формат `путь_в_реестре|название`), требует прав администратора.
- **Установка по пресету** — `profiles/<имя>.txt` со списком имён файлов: скрипт сам решает, что уже есть локально, что надо докачать по `links_download.txt`, а чего нет нигде — и покажет это до начала работы.
- **Логи по типам** — отдельные файлы для скачивания, установки, удаления, очистки реестра и пресетов; в меню «Показать логи» открывается последний лог нужного типа.
- **Отчёт по сессии** — общий `session-report.txt` с ПК, пользователем, версией и итогами каждой операции.
- **Статус в шапке меню** — число и размер файлов в `Progs`, наличие интернета, права администратора.
- **Перезапуск от администратора** — через UAC из главного меню (пункт 9).
- **История версий** — экран «О программе».

## Структура репозитория

```
Progs.bat              # сам скрипт
links/
  links.txt            # ссылки для открытия в браузере (URL|название)
  links_download.txt   # ссылки для скачивания (URL|имя.exe)
  registry.txt         # разделы реестра для удаления
docs/
  USAGE.md             # подробная инструкция
README.md
LICENSE
```

Папки `Progs/`, `Logs/` и `profiles/` создаются скриптом при первом запуске. `Progs/` и `Logs/` добавлены в `.gitignore`.

> **Внимание.** В `links/registry.txt` по умолчанию лежит пример со стандартными папками «Этого компьютера» (Загрузки, Изображения, Музыка, Документы, Видео, Рабочий стол, Объёмные объекты). Пункт «Очистка реестра» удаляет перечисленные разделы — проверьте список перед запуском.

## Open source

Проект распространяется под лицензией [MIT](LICENSE) и открыт для issue и pull request'ов. При этом он сознательно остаётся «один `.bat` + стандартные средства Windows» — без внешних зависимостей и сборки.

Если нашли баг или хотите предложить функцию — создайте Issue. Для PR: форкните репозиторий, создайте ветку, внесите изменения и откройте pull request, сохраняя стиль скрипта и не добавляя зависимостей.

> **Кодировка.** `Progs.bat` и `links/registry.txt` хранятся в кодировке **CP866** (OEM, кириллица консоли Windows). Не пересохраняйте их в UTF-8 — русский текст в консоли превратится в «кракозябры». Подробнее — в [docs/USAGE.md](docs/USAGE.md#кодировка-и-пути).
