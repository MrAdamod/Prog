# Progs — инструкция по использованию

Портативный менеджер установки программ для Windows в одном `.bat`-файле. Работает из любой папки (включая флешку), корректно обрабатывает пути с пробелами и русскими буквами. Все рабочие папки создаются автоматически при первом запуске.

## Что лежит рядом

```
Progs.bat              # сам скрипт
README.md              # описание проекта
links/                 # ссылки и списки
  links.txt            # ссылки для открытия в браузере
  links_download.txt   # ссылки для скачивания (URL|имя.exe)
  registry.txt         # разделы реестра для удаления
Progs/                 # создаётся при первом запуске: сюда качаются установщики
Logs/                  # создаётся при первом запуске: логи и отчёт по сессии
profiles/              # создаётся при первом запуске: пресеты (txt со списком имён файлов)
```

## Быстрый старт

1. Запустите `Progs.bat` двойным щелчком.
2. При первом запуске автоматически создадутся папки `links`, `Progs`, `Logs`, `profiles`.
3. Откройте `links\links_download.txt` и добавьте строки вида:
   ```
   https://example.com/app.exe|app.exe
   ```
4. В главном меню выберите `1` — скачать, затем `2` — установить.

## Главное меню

| Пункт | Действие |
|-------|----------|
| `1` | Скачать программы из `links_download.txt` |
| `2` | Установить `.exe`/`.msi` из `Progs` |
| `3` | Удалить файлы из `Progs` |
| `4` | Открыть ссылки из `links.txt` в браузере |
| `5` | Работа с txt: открыть/дополнить списки ссылок |
| `6` | Показать логи (последний лог нужного типа) |
| `7` | Удалить разделы реестра по `registry.txt` |
| `8` | Установить по пресету из `profiles/` |
| `9` | Перезапустить от администратора (UAC) |
| `10` | О программе / история версий |
| `0` | Выход |

## Выбор элементов

Во всех списках (скачивание, установка, удаление, ссылки, реестр) поддерживается:

- одиночные номера: `2 5 7`;
- диапазоны через тире: `1-3 6 8-10`;
- `A` — выбрать всё;
- `0` — отмена.

## Скачивание (пункт 1)

Файл `links\links_download.txt`, по одной строке на файл:

```
URL|имя_файла.exe
```

Пример:

```
https://example.com/setup.exe|setup.exe
https://example.com/tool.msi|tool.msi
```

Уже скачанные файлы (совпадает имя в `Progs`) пропускаются. Скачивание идёт через `curl`.

## Установка (пункт 2)

Берутся все `.exe` и `.msi` из папки `Progs`. Установка идёт через `start /wait`; коды `1602`/`1223` (отмена пользователем) и `3010` (нужна перезагрузка) обрабатываются отдельно. Для установки в защищённые места может потребоваться запуск от администратора (пункт `9`).

## Открытие ссылок (пункт 4)

Файл `links\links.txt`, формат:

```
URL|название
```

Название необязательно — если его нет, в меню показывается сам URL. Ссылки открываются в браузере по умолчанию.

## Работа с txt (пункт 5)

Позволяет открыть `links.txt` / `links_download.txt` в блокноте или добавить новую ссылку прямо из скрипта, не редактируя файлы вручную.

## Очистка реестра (пункт 7)

Файл `links\registry.txt`, формат:

```
путь_в_реестре|название
```

Пример:

```
HKCU\Software\ExampleApp|Example App
HKLM\Software\ExampleTool|Example Tool
```

Требуются права администратора — для разделов `HKLM` без них удаление не сработает. Запустите скрипт через пункт `9` и повторите.

> Файл `links/registry.txt` из репозитория содержит пример со стандартными папками «Этого компьютера». Перед запуском проверьте, что в нём остались только те разделы, которые вы действительно хотите удалить.

## Установка по пресету (пункт 8)

Создайте файл `profiles\Мой набор.txt` со списком имён файлов, по одному на строку:

```
setup.exe
tool.msi
```

Скрипт проверит, что уже есть локально в `Progs`, что можно докачать по `links_download.txt`, а чего нет нигде — и покажет это до начала работы. После подтверждения скачает недостающее и установит всё по порядку.

## Логи

- `Logs\download-log_*.txt` — скачивание;
- `Logs\install-log_*.txt` — установка;
- `Logs\delete-log_*.txt` — удаление;
- `Logs\regclean-log_*.txt` — очистка реестра;
- `Logs\profile-log_*.txt` — установка по пресету;
- `Logs\session-report_*.txt` — общий отчёт по сессии (ПК, пользователь, версия, итоги операций).

Пункт `6` открывает последний лог выбранного типа.

## Требования

- Windows 10/11 (используется `curl`, `powershell` для подсчёта размера, `choice`, `reg`).
- Для очистки реестра в `HKLM` — права администратора (пункт `9`).

## Кодировка и пути

- Все пути в скрипте в кавычках, работа идёт относительно папки скрипта (`cd /d "%~dp0"`), поэтому пробелы и русские буквы в путях допустимы.
- `Progs.bat` и `links/registry.txt` в репозитории хранятся в кодировке **CP866** (OEM-кодировка русской консоли Windows), переводы строк — CRLF. Скрипт не вызывает `chcp`, поэтому русский текст в консоли отображается корректно именно в этой кодировке.
- Если редактируете `.bat`, сохраняйте его в той же кодировке (CP866 / «DOS Cyrillic Russian»), иначе русский текст в меню превратится в «кракозябры». Если хотите перейти на UTF-8, добавьте `chcp 65001 >nul` в начало скрипта и пересохраните файл в UTF-8 **без BOM** (учтите, что это может ломать вывод некоторых утилит).
- Для защиты от случайной перекодировки и смены переводов строк в репозитории настроен `.gitattributes`.

## Ограничения

- Списки и пресеты — plain text, без экранирования `|` внутри URL.
- Скрипт не проверяет цифровые подписи установщиков — качайте только из доверенных источников. Проверка подписей — в планах.
